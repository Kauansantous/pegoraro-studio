# Adicionar um novo relatório

1. Duplique a pasta completa do imóvel (por exemplo, `casa-capricornio`) e renomeie a cópia.
2. Dentro da cópia, substitua `report.pdf` pelo PDF novo.
3. Edite apenas o `report.json` que está na mesma pasta e altere o título/textos.
4. Faça commit e publique. A URL será `/diagnostico/nome-do-imovel/`.

Não é necessário editar HTML, CSS ou JavaScript.
