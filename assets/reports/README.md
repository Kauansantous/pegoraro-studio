# Adicionar um novo relatório

1. Duplique a pasta `_template` e renomeie-a com um slug simples, por exemplo `casa-capricornio`.
2. Coloque o PDF final dentro dela com o nome `report.pdf`.
3. Abra `report.json` e altere somente os textos necessários.
4. Faça commit e publique.
5. Acesse: `/property-performance-report/?report=casa-capricornio`

Não é necessário editar HTML, CSS ou JavaScript.
